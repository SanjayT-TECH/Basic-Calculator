Simple Calculator Program

This project is a basic calculator application designed to perform the four fundamental arithmetic operations: addition, subtraction, multiplication, and division. The calculator allows users to input two numbers and select an operation to quickly compute the result.

The main objective of this project is to demonstrate the implementation of basic mathematical operations using programming logic. It is a beginner-friendly project that helps in understanding core programming concepts such as user input, conditional statements, functions, and arithmetic operators.

The calculator is capable of performing the following operations:

Addition – Adds two numbers and returns the sum.

Subtraction – Subtracts the second number from the first number.

Multiplication – Multiplies two numbers to produce the product.

Division – Divides the first number by the second number and returns the quotient.

This project is useful for beginners who are learning programming fundamentals and want to practice implementing simple logic in a real program. The calculator provides a simple and efficient way to perform calculations and demonstrates how basic mathematical operations can be handled programmatically.
